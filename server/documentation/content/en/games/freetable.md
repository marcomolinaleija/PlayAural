\*\*Free Tables\*\*

A free table is a place to talk by text and voice without starting a game. There are no turns, bots, scores, or winners.

\*\*Joining and Leaving\*\*

Choose Create a free table in the main menu to become its host. Other people can find a public table in Active tables, or join by invitation. Choose Leave table to leave. When the host leaves, another person at the table becomes host; the table closes when nobody remains.

\*\*Participants and Voice\*\*

Use Who's at the table to open the participants menu. Read participants and table host announces how many people are present, their names, and the host. Spectators carried over from a game are included. Bots in a game are announced separately and are not counted as people.

Voice chat works like any other table: join the voice channel to listen, then enable your microphone when you want to speak. The host can manage voice permissions and table membership. Text chat remains available alongside voice.

\*\*Switching Activities\*\*

The host can choose Choose a game, or use Host Management > Switch game. Confirming starts a fresh waiting lobby for the chosen game, preserving the people, playing or spectating roles, host, privacy, bans, and voice channel. Choose a game with enough seats for the current players.

To return from a game, open Host Management > Switch game and select Free table. Confirming discards the current match and removes bots. People and the voice channel remain at the same table. Cancelling keeps the current activity.

\*\*Privacy and Recovery\*\*

Use Host Management to make the table public or private, invite people, transfer ownership, and remove participants. An open table can be recovered after a managed server restart; reconnect during the recovery period. Free tables have no match to save manually.

\*\*Keyboard Shortcuts\*\*

W: Announce the people and table host.
Ctrl+W or Ctrl+U: Open the participants menu. In a browser, use Ctrl+U if Ctrl+W closes the tab.
Ctrl+M: Open Host Management.
Ctrl+Q: Leave the table.
Ctrl+F1: Open this guide.
Escape: Open the actions menu or go back.

In games that previously used W for a game action, that action is now on Alt+W. On touch clients, the participants menu and spoken roster are available as menu choices.
